# Premier League Transfer Fee Predictor ⚽

A Machine Learning project that predicts football player transfer fees using historical Premier League transfer data.

## 📌 Project Overview

This project uses Machine Learning to estimate a player's transfer fee based on details such as age, position, clubs, transfer year, and country.

## 🛠️ Technologies Used

* Python
* Pandas
* Scikit-learn
* Streamlit
* Random Forest Regression
* Pickle

## ✨ Features

* Predicts football player transfer fees
* Uses historical transfer data
* Interactive Streamlit interface
* Machine Learning-based prediction

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/phenomenal76/PremierLeagueTransferPredictor.git
```

2. Open the project folder:

```bash
cd PremierLeagueTransferPredictor
```

3. Install required libraries:

```bash
pip install pandas scikit-learn streamlit
```

4. Run the Streamlit application:

```bash
python -m streamlit run src/app.py
```
